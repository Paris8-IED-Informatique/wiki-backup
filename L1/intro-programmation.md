# Premiers pas avec Python et Visual Studio Code

## Installer Python

• Téléchargez et installez la dernière version de [Python](https://www.python.org).
• Important : Cochez bien la case `Add Python to PATH` (Ajouter Python au PATH) au tout début de l'installation sous Windows.

## Installer Visual Studio Code

• Téléchargez et installez [Visual Studio Code](https://code.visualstudio.com).
• Ouvrez VS Code, puis allez dans l'onglet **Extensions** (icône des carrés sur la barre latérale gauche).
• Recherchez et installez l'extension officielle **Python** (développée par Microsoft).

## Créer et exécuter votre premier script

* Créez un nouveau dossier sur votre ordinateur pour y ranger vos projets.
* Ouvrez ce dossier dans VS Code (Fichier > Ouvrir le dossier).
* Créez un nouveau fichier nommé `mon_script.py`.
* Écrivez votre première instruction dans l'éditeur

```python
print("Mon premier code python")
```

* Enregistrez le fichier.
* Cliquez sur le bouton de lecture (le triangle **Play** en haut à droite) ou ouvrez le terminal intégré et tapez

```shell
python3 mon_script.py
```
